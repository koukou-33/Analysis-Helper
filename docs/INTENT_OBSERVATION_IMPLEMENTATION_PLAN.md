# 多对象意图与精细观测实施计划

日期：2026-11-13。依据：[AH-028～AH-031](issues/AH-028-031.md)。用户已授权实施、提交和推送。

## 本轮范围

1. 多小区及成对对象范围、结构化模型意图、明确的同主体声明、问题与界面范围冲突提示。
2. 保留同秒不同无线观测，明确资源维度、真实冲突和顺序不确定性；不构造毫秒时间。
3. 多小区联合视图，未确认同步时分面显示各自观测序列；完整证据和预览使用相同排序。
4. 冻结前逐小区数据覆盖审核与有界补查；冻结后结论校验和有限修订，工具格式错误保留具体安全诊断。
5. 历史请求、动作恢复和证据兼容，定向与全量回归，真实样例离线复验，更新设计和现场操作说明。

## 实施组织

范围和意图、观测和绘图、工具修复和数据审核分别实现后，由主流程集成。顶层仍为 plan → agent loop → explain → report；结构化意图绑定固定请求，审核结果进入冻结包及报告。明确问题可直接执行，真实范围冲突才澄清。

现有修复与问题方案先提交为 `d41f129`。用户本地 TestData 保留，不发布到远端。实现过程中不改变原始样例文件和旧证据，不展示或提交 .env 内容。

## 验证与交付

先验证范围/同秒变化/质量阻断/多对象绘图/格式修复/审核边界，再完整回归。样例测试核对两个小区行数、有效点和 TA 原始值变化；32767 语义未知仍明确标注，不能推定为无效或正常业务值。所有发布结论区分已验证能力与仍需现场确认的规则。

## 实施结果

- 新增 `intent_resolution.py`，网页和CLI诊断入口使用同一结构化意图解析；意图阶段最多两次尝试，共享20秒期限，与后续分析预算分别记录。模型失败显示明确解析回退，真实范围冲突保留消歧。
- Scope支持多小区和配对OR对象，保持旧空字段序列化/hash；分析请求保存主体成员、目标及任务。左侧支持逗号分隔小区，历史分析可作为追问语义上下文，严格父群体仍单独显式选择。
- 新增 `observations.py`，查询、统计、预览和图表采用observations.v2。各文件/资源/RB独立序列；回绕、重置和不明顺序断线，缺失/冲突仅影响对应观测。联合视图默认最多12对象并优先覆盖各小区，共享2000预览点预算。
- 新增 `data_audit.py` 与 `task_review.py`，冻结前检查完整证据、对象和精度，有限补齐趋势；语义目标需证据绑定审核，允许最多一次有预算的工具补查。技术、预算、数据限制不冒充完成。
- 结论审核沿用最多三次结构化解释校验，新增可恢复的审核记录；冻结后不调数据工具。报告和证据索引包含数据/任务/结论审核。
- `expert_tools` 对结构错误最多修复两次，持久化安全字段定位、错误类型、尝试次数；执行失败不重放。搜索结果返回出处、版本和有限原文片段。
