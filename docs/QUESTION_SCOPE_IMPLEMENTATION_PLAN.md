## 关键验收用例

1. 输入“1911这个用户的TA变化趋势是什么样”：确认页显示crnti=1911、TA→taValue、继承的小区/时间、原始值单位状态；确认后所有产物满足该范围。
2. 文本1911与界面CRNTI=1912冲突：阻止执行，用户选择后才生成请求；不得混用基础统计1912与模型查询1911。
3. 多小区复用CRNTI、会话间隔断开、同时间多资源冲突、TA全空或非法、稀疏观测均不自动拼线或推断物理原因。
4. 确认后修改问题、数据版本、字段映射、范围，或者重试时切换UI会话：旧请求不能被静默改写。
5. 预览裁剪、时间桶聚合、超预算、模型失败和未确认单位：保留完整证据及明确边界，不声称趋势问题已经完整回答。
