## 已知能力边界

- 采用提供的字段样式和默认四流/30 kHz/单站点约定。不自动识别混合版本、多站点或特殊子载波配置；应分别加载并确认映射。波束分类是用户指定的临时数组维度规则，不是物理语义推断。
- m1.3 新增补充标量数字字段用于特性查询。重复同名列、未确认数组不自动加入该关系；单位未确认时不生成带单位的数字结论。m1.2 历史数据仍可恢复，但需显式重新加载才能获得新字段。
- 特性文档可使用明确的 YAML 契约，也可直接提供 Markdown 原文。配置模型后可提取 FeatureSpec，必须通过结构及原文逐字引用校验；没有明确充分规则时保留未知。真实模型的语义提取准确性仍需现场评估，含糊规则不自动补造。模板见 docs/templates。
- TEMPORAL_RELATE 使用同对象、向后包含端点时间窗内的存在性判断，不把一对多匹配展开。其他时序配对语义必须新增算子，不静默套用此策略。
- 文本诊断可完整运行；启用视觉服务后，在存在历史图且当前 PNG 导出成功时执行定性比对。未配置、无参考图、导出或服务失败时明确标记本轮未完成视觉比对。视觉输出不替代表格数字，不确认根因；真实视觉服务联调尚未完成。
- 手动 SQL 只支持受控 SELECT/CTE 和函数白名单，不能读取数据集物理表绕过范围。探索性 SQL 不自动用于特性确认。
- 查询时限 30 秒、内存 512 MB、输出最多 100 万行、汇总最多 10 万组。完整查询表落盘；画布表预览 100 行，时序预览最多 2000 个秒桶。超过限制须缩小范围，不发布截断结果冒充全量统计。
- UI 置顶标记保存在会话注册库，不提升证据等级。完整图表可下载 HTML；图片审核上传支持 PNG/JPEG/WebP，每张最多 10 MB / 2000 万像素。
- 案例附带证据会验证文件哈希；从工作台生成的草稿在发布时自动回放附带计划/SQL/时序/特性查询，并对完整结果作多重集比较。固定数据版本缺失或结果不一致会阻止发布。纯文字案例无需可执行查询。
- 新加载数据会建立新版本，未实现跨加载自动复用数据库。中断动作明确重试会重新生成证据，不覆盖旧文件。历史成功动作读取已有结果，不重新计算。
