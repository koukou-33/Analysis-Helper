## 验证结果

45 项 unittest/AppTest 全部通过，包含文件发现正反例、合法/非法日期、440 字段目录、无补充表时模式/默认查询仍可运行、范围内单列值与 NULL、嵌套条件字段提取、实际生效标志、SQL、特性判定和 UI 流程。初轮出现一次 Windows 临时目录重命名拒绝访问；完整复跑通过，未修改数据发布语义。

性能复现（仓库根目录）：`.venv\Scripts\python.exe -m scripts.benchmark_scope`。脚本生成独立合成 DuckDB 表，不读取现场 CSV；输出位于忽略的 `workspace_storage/scope_benchmark/`。

本机实测：77,273 条资源记录 × 440 字段 = **34,000,120 行**补充明细，512 MB DuckDB 内存限制、2 线程，选择 logicCellId=0（38,637 条记录）。

| 测量项 | 耗时 |
| --- | ---: |
| 规划字段目录获取 | 0.0064 秒 |
| 基础范围准备，不读补充明细 | 0.0167 秒 |
| 单补充字段过滤、聚合和关联 | 0.0500 秒 |

校验了范围内记录数和单字段总和。以上为合成数据、生成后同进程测量，未包括导入、模型、全量统计和证据导出，不是现场端到端耗时承诺。显式全字段 SQL、多字段复杂特性及磁盘冷缓存仍需现场测试。
